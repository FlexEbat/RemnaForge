# Шаблоны подписки (Subscription Templates)

Файлы в этой папке — не то, что устанавливает RemnaForge автоматически. Это готовые Xray JSON шаблоны подписки для панели Remnawave: панель хранит и раздаёт их сама, через собственный веб-интерфейс и API (`/api/subscription-templates`), никак не связанные с установкой панели или ноды. RemnaForge их не загружает и не назначает — этот шаг всегда делается вручную, потому что шаблон назначается на конкретный Host, а какой именно Host выбрать — решение оператора, не то, что можно угадать при установке.

## xrayWithoutRU.json

Клиентский конфиг с раздельным туннелированием: трафик российских сайтов и сервисов (`geosite:category-ru`, `geoip:ru`, Apple/Huawei/Xiaomi/Android-инфраструктура) идёт напрямую, всё остальное — через прокси. Несколько явно перечисленных доменов (`habr.com`, `4pda.to`, `4pda.ru`, `jut.su`) идут через прокси, несмотря на российскую юрисдикцию.

Содержит директиву `remnawave.injectHosts` с селектором `sameTagAsRecipient` — панель сама подставит реальный VLESS/Reality outbound с тегом `proxy` при генерации подписки для конкретного пользователя, ничего вручную прописывать не нужно. `socks`/`http` inbound'ы — локальные точки входа для настольного клиента; замените `CHANGE_ME` на свои логин/пароль перед использованием, если планируете раздавать этот конфиг за пределы доверенного круга.

### Как подключить

1. В панели: **Templates → Subscription Templates → Create** (или аналогичный пункт меню в вашей версии панели).
2. Тип шаблона — **XRAY_JSON**, имя — на ваше усмотрение (например, `xrayWithoutRU`).
3. Вставьте содержимое `xrayWithoutRU.json` в поле конфига, сохраните.
4. Откройте нужный **Host** → раздел **Расширенные** → поле **Шаблон Xray JSON** → выберите только что созданный шаблон.
5. Пользователи, чья подписка формируется через этот Host, получат конфиг в этом формате.

Актуальность полей и точные названия пунктов меню зависят от версии панели — сверяйтесь с [f.docs.rw](https://f.docs.rw), если что-то не совпадает с описанным здесь.
